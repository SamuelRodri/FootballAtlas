# Vision

## What is Football Atlas?

Football Atlas is a web platform that allows users to analyze football from a geographical perspective.

The platform aims to visualize relationships between countries, players, clubs and competitions using interactive maps and geographical visualizations.

## Goals

- Learn GIS-related web technologies.
- Build a portfolio project.
- Explore football data through maps.
- Prioritize public or free data sources.

## Non Goals

- Compete with Transfermarkt.
- Create a betting platform.
- Build a social network.
